<h1>Open Source Intelligence</h1>


<h2>Description</h2>
This project involved simulating the reconnaissance phase of a penetration test, focusing on Master.D and the assets publicly associated with the masterd.pt domain.
The investigation was conducted as part of the final project for the Cybersecurity training programme, relying exclusively on open sources and adhering to the scope defined for the exercise.
<br />


<h2>Ojectives</h2>

- <b>Identify domains and subdomains associated with the entity under investigation.</b>
- <b>Collect publicly available information on IP addresses, hosting, geolocation, and identifiable services.</b>
- <b>Analyse functional contacts and publicly indexed information.</b>
- <b>Correlate the collected data and represent the identified relationships.</b>


<h2>Methodology and Tools </h2>
The process included researching publicly accessible information, identifying related assets, analysing available technical data, and graphically representing the observed relationships. The investigation was conducted using open sources and passive reconnaissance tools:

- <b>Google</b>
- <b>Censys</b>
- <b>Netcraft Site Report</b>
- <b>MaxMind GeoIP</b>
- <b>Maltego</b>


<h2>Scope and Limitations</h2>

The results represent the information observed during the exercise and do not constitute a comprehensive security audit or a validation of the security of the systems analysed. 
The exercise was limited to the collection and analysis of information through open sources. No vulnerability exploitation tests or direct interactions with the entity's systems, networks, or employees were conducted, with the exception of downloading publicly indexed documents, as described in the report.
